iOS implementation handoff

Live source of truth

This inspector describes behavior, authored presets and the currently rendered pose. Values use degrees and avatar units. The iOS renderer should normalize positions against head width and height, then animate from its current presentation values whenever a state is interrupted.

Current runtime

Transition contract

1

Read the current rendered pose when a new state arrives. Never jump back to a preset’s authored start.

2

Set new expression, gaze and head-motion targets. Springs remain interruptible at every frame.

3

Run orbit as a continuous phase layer. Entry begins at each eye’s visible anchor.

4

Apply shape projection and clipping after pose interpolation; plane eyes intentionally render above the surface.
